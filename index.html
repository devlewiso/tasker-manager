      Restore from file

      Automatic snapshots

      Where your data lives

      Saved on every change in two places inside this browser (localStorage + IndexedDB). It survives closing the tab, restarting and updates. It's only lost if you clear this site's browsing data, use a private window or change browser or device — that's what the backup file is for.
